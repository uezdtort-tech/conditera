### Onboarding кондитера (POST /api/confectioner/onboarding)

Принимает multipart/form-data:
- `businessName` (string, 3..100, required)
- `description` (string, ≥30 символов, required)
- `city` (string, required)
- `phone` (string, optional)
- `legalStatus` (NPD | IP | OOO | PHYSICAL, required)
- `inn` (string, 10 или 12 цифр, required для IP/OOO)
- `specialization` (JSON array string, optional)
- `selfPickup` ("true" | "false", default "true")
- `avatar` (file, optional, ≤5 МБ)
- `cover` (file, optional, ≤5 МБ)
- `portfolioFiles` (file[], 0..8, ≤10 МБ)

Логика:
1. Требует CONFECTIONER роль (проверяет через user_roles table)
2. Если уже есть строка в confectioners по userId — возвращает 409
3. Загружает avatar в bucket "avatars", cover в "covers", portfolioFiles в "portfolio" (путь: `{userId}/{timestamp}-{i}.{ext}`)
4. Создаёт строку в public.confectioners с verified=false, verificationStatus="pending"
5. Запускает tryAutoApprove (DaData, если IP/OOO с валидным ИНН)
6. Push-уведомление всем ADMIN/SUPER_ADMIN

Также создан `POST /api/confectioner/portfolio` — добавление файлов к существующему профилю (после onboarding), лимит 50 total.

- **Гидратация Zustand:** при получении live-данных вызывает setConfectioners() → ConfectionerProfilePage и ConfectionersPage тоже видят live-данные
- **Dev-бейдж:** "src: Supabase (live) | mock (БД недоступна) | mock (пусто в БД)"
- **Анимация:** CSS marquee-x keyframe, pause on hover, edge-fade mask, длительность ~12s на карточку
- **Карточка:** avatar + verified-чекмарка, businessName, city + specialization[0], rating, trustLevel badge, миниатюра работы (portfolioImages[0])
