## 📋 ГРУППА 1: БАЗОВЫЕ РОЛИ (5)

### 1. CUSTOMER (Покупатель)

**Профиль (`CustomerProfile`):**
- Поля: `defaultDeliveryAddress`, `preferredPaymentMethod`, `dietaryRestrictions[]`, `allergens[]`, `budgetRange`, `favoriteFlavors[]`, `birthDate` (для бонусов)
- Расширяет: `profiles` (name, avatar, phone)
- Заполняется при первой регистрации

**Дашборд (`CustomerDashboard`, 771 строка):**
- **Заказы** — список активных и завершённых, фильтр по статусу (PENDING → COMPLETED)
- **Избранное** (Wishlist) — сохранённые товары с ценой и наличием
- **Адреса доставки** — CRUD адресов (дом, работа, мама)
- **Бонусы и лояльность** — текущий баланс, история транзакций (EARN/REDEEM/EXPIRE), уровень (BRONZE/SILVER/GOLD/PLATINUM)
- **Переговоры** (Cake Builder inquiries) — отправленные запросы кондитерам, статусы
- **Сообщения** — список чатов с кондитерами и support
- **Уведомления** — in-app + push (Web Push API)
- **Подарочные сертификаты** — купленные и активные
- **Реферальная программа** — реферальная ссылка, статистика приглашённых
- **Настройки профиля** — через `ProfileSettings` (смена пароля, 2FA, приватность)
- **Telegram-бот** — связь аккаунта с Telegram для уведомлений

**Tabs:**
1. Обзор — KPI (заказы, бонусы, активные переговоры)
2. Заказы — таблица с пагинацией
3. Избранное — grid-карточки товаров
4. Адреса — CRUD
5. Бонусы — график начислений по месяцам
6. Переговоры — Kanban-style список
7. Сообщения — preview последнего сообщения
8. Настройки — форма

### 2. CONFECTIONER (Кондитер)

**Профиль (`Confectioner`, основная модель):**
- `businessName`, `slug` (URL), `description`, `avatar`, `coverImage`
- `city`, `region`, `deliveryCities[]`, `deliveryRadius`
- `specialization[]` (торты, капкейки, макаронс, ...)
- `rating`, `reviewsCount`, `ordersCount`
- `verified` (boolean), `trustLevel` (NEW/VERIFIED/MASTER/EXPERT)
- `legalInfo` (ИНН, ОГРН, тип: individual/legal, taxMode)
- `tariff` (START/BASIC/PREMIUM/BUSINESS)
- `balance`, `totalEarnings`, `commissionRate`
- `portfolio` (массив изображений работ)
- `certificates[]` (Халяль, Кошер, ISO, HACCP)
- `responseTime` (среднее время ответа на inquiry)
- `productionCapacity` (тортов в день)

**Дашборд (`ConfectionerDashboard`, 1204 строки):**
- **Обзор** — KPI: активные заказы, доход за месяц, рейтинг, новые inquiries
- **Входящие запросы** (Cake Builder inquiries) — список с фильтрами по городу, бюджету
- **Переговоры** — предлагание цены, accept/decline/counter
- **Заказы** — календарь заказов по датам доставки, смена статусов (PREPARING → READY → IN_DELIVERY)
- **Каталог** (CRUD товаров) — продукты с фото, ценами, статусом публикации
- **Финансы** — доход, расходы (BusinessExpense), комиссии, payout-запросы
- **Налоги** (TaxReport) — отчёты по периодам, PDF-выгрузка
- **Портфолио** — загрузка фото работ, категоризация
- **Ателье** (ConfectionerAtelier) — студия для мастер-классов, расписание
- **Мастер-классы** (ConfectionerLesson) — создание, запись учеников
- **Дегустации** — расписание, бронирование
- **Канал** (ChannelPost + ChannelStory) — контент-маркетинг (как Instagram stories)
- **Рецепты** (Recipe) — публикация, статистика, принятия (RecipeAcceptance)
- **3D-разрезы** (ProductSlice) — визуализация торта внутри
- **Промо-акции** — создание промокодов, баннеров
- **SimpleX** (опционально) — E2E-чат с premium-клиентами
- **Настройки** — через ProfileSettings

**Tabs (16+):** Обзор, Запросы, Переговоры, Заказы, Календарь, Каталог, Финансы, Налоги, Портфолио, Ателье, Мастер-классы, Дегустации, Канал, Рецепты, 3D-разрезы, Промо, Настройки

### 7. MODERATOR (Модератор контента)

**Профиль (`ModeratorProfile`):**
- `moderationZones[]` (PRODUCTS, REVIEWS, CHAT, BROADCAST)
- `seniority` (JUNIOR, MIDDLE, SENIOR)
- `decisionsCount`, `accuracyRate`
- `canBanUsers` (boolean)

**Дашборд (`ModeratorDashboard`, 423 строки):**
- **Очередь модерации** (ModerationQueue) — список контента для проверки
- **Типы контента:** продукты, отзывы, сообщения чата, рассылки, площадки, услуги, события, профили, комментарии

- **Правила** (ModerationRule) — regex, keywords, url_pattern, email_pattern с action (reject/flag/warn)
- **Чёрный список** (BlacklistEntry) — IP, email, телефоны
- **Статистика** — обработано за смену, отклонено/одобрено, accuracy
- **Эскалация** — спорные случаи на админ-ревью (OperatorEscalation)
- **Шаблонные ответы** (CannedResponse) — для типовых ситуаций

**Tabs:** Очередь, Жалобы, Правила, Чёрный список, Статистика, Эскалации, Шаблоны

## 🎯 РЕКОМЕНДАЦИИ ДЛЯ v2.0

### Приоритеты реализации (после миграции на Supabase)

1. **Сначала — 5 базовых ролей** (CUSTOMER, CONFECTIONER, COURIER, SUPPLIER, ADMIN) — это 80% трафика
2. **Затем — 3 модерации** (MODERATOR, SUPPORT, GUEST)
3. **Потом — 5 расширенных** (BLOGGER, TASTER, NUTRITIONIST, COPYWRITER, CORPORATE_CLIENT)
4. **Финал — 8 нишевых** (остальные, включая 4 нереализованных)

### Технические принципы v2.0

- **Все дашборды** через единый `DashboardShell` (layout + sidebar + tabs)
- **Данные** только через TanStack Query + supabase-js (никаких MOCK_*)
- **Типы** из Supabase schema (`supabase gen types typescript`)
- **RLS** на уровне БД → нет нужды в проверке ролей в коде
- **Lazy loading** каждого tab через `next/dynamic`
- **Realtime** для живых данных (заказы, сообщения) через Supabase Realtime
