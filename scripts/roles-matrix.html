Проблемы и рекомендации
🔴
ANIMATOR_AGENCY, RECREATION_CENTER, KIDS_CLUB — нет API и UI
3 роли объявлены в enum, но не имеют ни API endpoints, ни дашбордов, ни профильных моделей. Нужно либо реализовать (API + UI), либо удалить из enum если не планируются.
🟡
WHOLESALER → CONFECTIONER — нет отдельного API для оптовых заказов
Модель WholesalePrice есть, но нет API для оформления оптового заказа. Кондитер не видит оптовиков в дашборде. Нужно: GET /api/wholesaler/orders, POST /api/wholesaler/order.
🟡
BLOGGER → CONFECTIONER — нет системы бартера и реферальных отслеживаний
BloggerProfile есть, но нет API для создания рекламных постов, отслеживания реферальных переходов, расчёта комиссий блогерам.
🟡
FOOD_SERVICE → CONFECTIONER — нет API для регулярных B2B-поставок
FoodServiceProfile есть, но нет API для оформления контракта на регулярные поставки тортов в рестораны/кафе.
🟡
STUDIO → CONFECTIONER — нет API для бронирования фотосессий
StudioProfile есть, но нет API для заказа фотосъёмки тортов в студии, календаря бронирования.
🟡
MODERATOR → все роли — нет отдельного дашборда модератора
Модерация разбросана по admin-вкладкам. Нет единого очереди модерации (отзывы + фото + рецепты + начинки). Нужно: единый Moderator Dashboard с очередью.
🟡
ADMIN → COURIER — нет управления курьерами в админке
Курьеры есть в API, но в админ-панели нет вкладки управления курьерами (зоны, рейтинги, бан/разбан, назначение на заказы вручную).
🔵
TASTER ↔ CONFECTIONER live-commerce — частично
Live-стримы есть, но нет интеграции с дегустаторами (оценка во время стрима, синхронная дегустация).
🔵
STUDIO ↔ BLOGGER — отсутствует
Нет связи между фотостудиями и блогерами для совместного контента.
🔵
FOOD_SERVICE ↔ SUPPLIER — отсутствует
Рестораны не могут заказывать ингредиенты напрямую у поставщиков (только через кондитеров).
