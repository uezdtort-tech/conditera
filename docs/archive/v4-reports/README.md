# Архив отчётов v4.x

Исторические release-отчёты эпохи v4.1–v4.8 (октябрь–ноябрь 2026), перемещённые из корня
репозитория при очистке Z-v31. Актуальные документы процесса — в `docs/operations/`
(PRODUCT_OPERATING_SYSTEM.md, PRODUCTION_RELEASE.md, ROLLBACK_RUNBOOK.md) и
`docs/audits/` (Z-v2x).

Содержимое не поддерживается — только для истории решений владельца.
