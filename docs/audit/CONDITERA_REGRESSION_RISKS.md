## Независимые постоянные риски (не созданы этим сеансом)

1. **OOM dev-сервера** — Vitest и dev не гонять параллельно; при OOM: перезапуск, при необходимости чистка `.next/dev` (только при остановленном сервере).
2. **Snapshotter-drift** — skip-worktree (4 upload-файла) + pre-commit guard; при появлении «удалений» в `git status` сначала `git ls-files -v | rg '^S '`, затем восстановление из `c8cc0bc`-blobs, не из памяти.
3. **Демо-данные в production** — гейт `NEXT_PUBLIC_DEMO_SEED`; admin/dashboard чист; при добавлении новых витрин обязателен `demoSeed()`-обёртка (33 существующие точки — ориентир).
4. **`chat_messages.room_id` legacy-колонка** — новые миграции должны не реанимировать её использование; runtime-ключ — `channel_id`.
5. **Локальная ветка main ahead 165** — публикация только явной командой владельца; перед push сверить diff против origin/main (перечень коммитов есть в отчёте).
