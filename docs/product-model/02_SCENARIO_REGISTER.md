# Conditera — реестр сквозных сценариев

**Статус:** DRAFT 0.1  
**Назначение:** единый реестр для моделирования, трассировки данных, нормативных требований, антифрода и тестов. Это стартовый перечень, а не заявление о полноте. Каждый сценарий будет детализирован по шаблону из `00_TARGET_OPERATING_MODEL.md`.

Статусы в этой версии — DRAFT. Приоритеты: **P0** — блокирует корректность/безопасность/деньги/законность; **P1** — необходим для полноценного продукта; **P2** — развитие.

## 12. Правила дальнейшего расширения реестра

- Новые сценарии добавляются с уникальным ID, не переиспользуя старые.
- Один сценарий может затрагивать несколько контуров; связи фиксируются явно.
- Один и тот же процесс описывается один раз и переиспользуется ссылками, а не копируется в разных разделах.
- Для каждого P0-сценария обязательны негативные тесты, проверка прав, идемпотентности, конкуренции и восстановления.
- Нельзя считать «проверено» сценарий, если часть шагов пропущена, заменена моками или выполнена на другом источнике данных.
- Все открытые вопросы остаются видимыми; отсутствие ответа не превращается в предположение.
