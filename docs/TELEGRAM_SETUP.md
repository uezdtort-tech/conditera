# 📱 Telegram Bot + Канал — настройка

> Пошаговая инструкция по созданию бота и канала для уведомлений «Уездного кондитера».

---

## 📋 Что вы получите

1. **Telegram-канал** — куда бот отправляет уведомления:
   - 🛒 Новый заказ (номер, клиент, сумма, состав)
   - 📞 Новый лид (имя, контакты, источник)
   - 🎫 Новый тикет поддержки (тема, приоритет, категория)
   - 💳 Оплата получена (сумма, заказ)
   - 👤 Новая регистрация пользователя
   - ❌ Ошибки приложения

2. **Telegram-бот** — команды для клиентов и админов:
   - `/start` — приветствие
   - `/help` — список команд
   - `/catalog` — ссылка на каталог
   - `/orders` — мои заказы
   - `/track UK-2025-0234` — отследить заказ
   - `/support` — контакты поддержки
   - `/contacts` — контакты кондитеров
   - `/stats` (админ) — статистика платформы
   - `/health` (админ) — статус сервисов
   - `/broadcast` (админ) — рассылка в канал

## 🚀 Настройка за 10 минут

### Шаг 1: Создать бота через @BotFather

1. Откройте Telegram, найдите **@BotFather**
2. Отправьте `/newbot`
3. Введите имя бота: `Уездный кондитер`
4. Введите username: `conditera_bot` (должен заканчиваться на `_bot`)
5. BotFather пришлёт **токен** вида:
   ```
   7891234567:AAEhBP-3Xy7vMn2KqLp5R8sT6uW9xYzAbCdEf
   ```
6. Скопируйте токен → это `TELEGRAM_BOT_TOKEN`

### Шаг 2: Создать Telegram-канал

1. В Telegram: **Меню → Создать канал**
2. Имя: `Уездный кондитер — Уведомления`
3. Описание: `Заказы, лиды, тикеты, ошибки`
4. Тип: **Приватный** (рекомендуется) или Публичный
5. Создайте канал

### Шаг 3: Добавить бота в канал администратором

1. Откройте канал → **Информация → Подписчики**
2. Найдите вашего бота по username (`@conditera_bot`)
3. Добавьте его как **администратора**
4. Дайте права:
   - ✅ Публикация сообщений
   - ✅ Редактирование сообщений
   - ✅ Удаление сообщений (опционально)
   - ❌ Добавление подписчиков (не нужно)

### Шаг 4: Получить ID канала

#### Для публичного канала:
- ID = `@username_канала` (например `@conditera_alerts`)

#### Для приватного канала:
1. Напишите любое сообщение в канал
2. Перешлите это сообщение боту **@userinfobot**
3. Бот пришлёт ID вида `-1001234567890`
4. Это и есть `TELEGRAM_CHANNEL_ID`

### Шаг 5: Получить ваш chat ID (для админ-команд)

1. Напишите боту **@userinfobot** сообщение `/start`
2. Бот пришлёт ваш ID (например `123456789`)
3. Это ваш `TELEGRAM_ADMIN_CHAT_IDS` (можно несколько через запятую)

### Шаг 6: Заполнить .env.production

```env
# Telegram Bot
TELEGRAM_BOT_TOKEN=7891234567:AAEhBP-3Xy7vMn2KqLp5R8sT6uW9xYzAbCdEf
TELEGRAM_CHANNEL_ID=-1001234567890
TELEGRAM_ADMIN_CHAT_IDS=123456789,987654321
```

### Шаг 7: Зарегистрировать webhook

После деплоя выполните:

```bash
# Через cron-secret
curl -X POST https://conditera.ru/api/telegram/setup-webhook \
  -H "X-Cron-Secret: $CRON_SECRET"

# Или с JWT админа
curl -X POST https://conditera.ru/api/telegram/setup-webhook \
  -H "Authorization: Bearer <admin-jwt>"
```

**Ответ:**
```json
{
  "success": true,
  "bot": {
    "username": "conditera_bot",
    "firstName": "Уездный кондитер"
  },
  "webhook": {
    "url": "https://conditera.ru/api/telegram/webhook",
    "set": true
  },
  "commands": true,
  "channelTest": true
}
```

### Шаг 8: Проверить

1. **Отправьте боту** `/start` — должны получить приветствие
2. **Отправьте** `/help` — список команд
3. **Отправьте** `/track UK-2025-0001` — статус заказа
4. **Проверьте канал** — туда должны прийти уведомления о новых заказах/лидах/тикетах
5. **Админ-команды** (только для ID из TELEGRAM_ADMIN_CHAT_IDS):
   - `/stats` — статистика платформы
   - `/health` — статус сервисов
   - `/broadcast Привет!` — сообщение в канал

## 🔒 Безопасность

- **Webhook** принимает POST только от Telegram (IP allowlist можно добавить в Caddy)
- **Админ-команды** проверяются по `TELEGRAM_ADMIN_CHAT_IDS`
- **Бот-токен** хранится в `.env.production` (не в коде)
- **CSRF exempt**: `/api/telegram/webhook` добавлен в список exempt paths (Telegram не отправляет CSRF-токен)

## 🛠️ Troubleshooting

### Бот не отвечает на команды
1. Проверьте что webhook установлен: `curl https://api.telegram.org/bot<TOKEN>/getWebhookInfo`
2. Проверьте что `TELEGRAM_BOT_TOKEN` задан в `.env.production`
3. Проверьте логи: `docker compose logs web | grep telegram`

### Уведомления не приходят в канал
1. Проверьте что `TELEGRAM_CHANNEL_ID` задан правильно
2. Проверьте что бот — администратор канала
3. Проверьте что бот может писать: отправьте тест через `/broadcast Тест`
4. Для приватных каналов: ID должен начинаться с `-100` (например `-1001234567890`)

### Админ-команды говорят «только для администраторов»
1. Проверьте что ваш chat ID добавлен в `TELEGRAM_ADMIN_CHAT_IDS`
2. ID должен быть без минуса (например `123456789`, не `-123456789`)
3. Узнать свой ID: напишите боту @userinfobot

### Webhook не работает (404 / 500)
1. Проверьте что домен `conditera.ru` доступен
2. Проверьте что Caddy проксирует `/api/telegram/webhook` на web:3000
3. Проверьте логи: `docker compose logs web | grep webhook`
