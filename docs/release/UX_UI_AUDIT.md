# UX/UI AUDIT — Z-v20

Метод: инвентаризация всех page.tsx из App Router + аудит по коду + скриншот-проверка
(Agent Browser: desktop 1440×900, mobile 375×812). Дизайн-система сохранена
(cream-фон `oklch(0.985 0.012 75)`, ягодный primary `oklch(0.42 0.18 25)`, графит —
без редизайна).

## Инвентаризация страниц (33 page.tsx)

App Router — «оболочка»: реальный UI — SPA-view через Zustand (`nav.view`); `page.tsx`
на под-маршрутах — заглушки `<RouteFallback view="…"/>` (единый шелл, SSR-friendly).
Footer sticky: `min-h-screen flex flex-col` + `<footer className="mt-auto">` — подтверждено.
`loading.tsx`/`error.tsx`/`global-error.tsx`/`not-found.tsx` — на корне; после Z-v20
добавлены сегментные `error.tsx` для `/checkout` и `/dashboard`.

### Принято как есть (с обоснованием)

- **D5 (Unsplash-стоки как контент платформы)** — витрина работает в dual-mode:
  при пустой БД остаётся demo-seed (задокументированное решение владельца —
  docs/KNOWN_LIMITATIONS.md №14). Замена изображений = контент от владельца.
- **D7 (полный микротекст-аудит)** — 792 вхождения в 79 файлах; массовая замена
  без визуальной проверки каждого места создаст больше рисков, чем пользы перед релизом.
- **D10 (терминология Сплит/СБП)** — переименование ID опций оплаты затрагивает
  checkout-контракт; отложено до отдельного UX-решения.
- **D12 (эмодзи-иконки вперемешку с lucide)** — консистентность иконок: P2-косметика,
  не блокер.
- **D15 (loading-состояния)** — 4 из ~85 дашбордов на Skeleton; остальные спиннеры —
  работает, унификация отложена.

## Проверено и подтверждено (без дефектов)

- Карточки тортов: квадратное фото, бейджи, цена, alt, disabled при недоступности, aria-label кнопок.
- Каталог на мобильном: фильтры в Sheet, сетка `grid-cols-2 sm:3 xl:4`, zero-result компонент.
- Checkout: 3 шага с индикатором, живой баннер выполнимости (`role="alert"`), idempotency-key, серверные суммы на success.
- Диалоги на мобильном: глобальный CSS прижимает max-w-2xl к full-screen; inputs 16px (без iOS-зума).
- Скриншоты: `/` (desktop+mobile) и `/cart` — без горизонтального скролла, footer прижат.
