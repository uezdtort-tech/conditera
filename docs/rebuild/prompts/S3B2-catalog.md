## 3. ЦЕЛЬ БЛОКА
Каталог с фильтрами/поиском/пагинацией, страница товара (состав,
аллергены, отзывы списком), API каталога v2.

## 4. ШАГИ
1. API (Route Handlers, все GET публичные; с rate-limit):
   - GET /api/products?category=&q=&minPrice=&maxPrice=&sort=&page=
     → пагинированный список (20/стр), только isPublished;
   - GET /api/products/:slug → карточка с составом, аллергенами,
     categoryId, агрегатом отзывов и СПИСКОМ отзывов (статус
     approved), пагинация отзывов;
   - GET /api/categories → дерево категорий;
   - POST /api/reviews (auth CUSTOMER+, CSRF) — отзыв с модерацией
     (status pending).
2. /catalog: сетка карточек (ShopCard), фильтры: категория (дерево из
   /api/categories), цена (range), поиск с debounce 400мс; сортировка
   (популярность/цена/новизна); пагинация (shadcn Pagination);
   URL-состояние фильтров (searchParams — ссылки шарятся).
   Определение категории — ТОЛЬКО categoryId из БД (закрыть
   guessCategory старого проекта, D11).
3. /catalog/[slug]: галерея изображений, цена/вес/сроки, блок «Состав»
   (ingredients — из БД, заполнен в seed), бейдж «Аллергены» с
   перечнем (allergens), вкладка «Отзывы»: список с пагинацией + форма
   отзыва для вошедшего покупателя (SafeHtml-рендер, статус «на
   модерации» после отправки), похожие товары (та же категория).
4. /confectioners: карточки кондитеров (бизнес-профили из profiles,
   роль CONFECTIONER) — рейтинг, число товаров, город; переход на
   фильтр каталога по кондитеру (?confectioner=).
5. Хлебные крошки: Каталог → Категория → Товар.
6. Скелетоны загрузки (shadcn Skeleton) для всех сеток; ошибки API —
   EmptyState с retry.
